Choosing retrieval and reranking

Match the strategy to the wording and complexity of the question. Start with Hybrid for mixed pharmaceutical queries, then compare results in the trace and evaluation pages.

  • Dense Retrieval (Semantic) — best for natural-language questions, paraphrases and concept searches where the same idea may use different words.
  • BM25 — best for exact terms such as drug names, compound codes, SOP numbers, equipment IDs, clause numbers and specific phrases.
  • TF-IDF — a lightweight lexical baseline for straightforward keyword-focused queries. Prefer BM25 for most exact-term searches.
  • Hybrid — combines semantic and BM25 results. A strong general choice when queries contain both concepts and exact terminology.
  • HyDE — useful for broad or descriptive questions where the user's wording differs greatly from the wording in the source documents. It creates a hypothetical passage for retrieval; the final answer still uses real retrieved passages.
  • MMR — useful when the top results are repetitive or many chunks come from the same document. It balances relevance with content diversity.
  • GraphRAG — best for multi-hop questions about relationships, such as which medicine is associated with a condition, procedure, contraindication or requirement, when those links were extracted into the graph.
  • GraphRAG + Hybrid Vector Search — a good choice for relationship questions that may also need direct semantic or exact-term evidence. It combines graph, dense and BM25 rankings.
Reranking happens after retrieval

No Reranking: fastest and simplest. Use when the initial ranking is already good or latency matters most.

Cohere Rerank (Cross-Encoder): useful when the initial candidate list contains near-matches and you need more precise query-to-passage relevance ordering. It scores each query-passage pair; hosted API usage limits apply.

LLM Reranker (Groq): useful for nuanced questions where relevance depends on context, but can be slower and is subject to model availability and free-tier limits.

Practical starting point: Hybrid + Cohere Rerank for mixed, high-precision searches; BM25 for identifiers; GraphRAG + Hybrid for relationship questions. Compare latency and retrieved passages before settling on a default.
