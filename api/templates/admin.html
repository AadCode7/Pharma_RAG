Choosing a chunking strategy

Choose based on how the source is organised. There is no single best method for every document.

  • Recursive Character — a good general-purpose starting point for mixed or inconsistently formatted text. It splits at natural boundaries where possible.
  • Section Aware — best for SOPs, policies, regulatory guidance, manuals and structured websites with clear headings. It keeps each heading with its section.
  • Parent / Child — useful for long technical documents where small, precise matches need the surrounding paragraph or section for context.
  • Semantic — useful for continuous explanatory prose, research summaries and articles where topic changes matter more than fixed lengths. It groups sentences with similar meaning.
  • Sentence Based — useful for short FAQs, articles and text where sentence boundaries must stay intact.
  • Fixed Size — a predictable baseline for simple, consistently written text. It can split a sentence or section, so it is less suitable for heavily structured material.
By source type

PDFs and text: use Section Aware for clear headings, Parent / Child for long manuals, or Recursive for mixed layouts.

Images: text is extracted with OCR first. Use Section Aware or Recursive for clean OCR; review OCR output when scans are faint, skewed or table-heavy.

Websites: use Section Aware for heading-led pages and Recursive for irregular pages. Page and section metadata are retained during website ingestion.

When is a knowledge graph most useful?

Enable graph indexing for entity-rich content that describes relationships: drug monographs, SOPs, clinical protocols, product specifications, safety guidance, and linked technical or regulatory pages. Graphs help connect entities such as medicines, ingredients, conditions, procedures, equipment and requirements across passages.

Graphs add less value to short, isolated notes, generic prose with few named entities, or poor OCR. Tables can be valuable when their headers and row relationships are preserved in the extracted text.
